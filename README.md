# Instagram Analysis Using CSV
code for Instagram Analysis using CSV file , consist of webpage with few names etc # Instagram Analytics Dashboard




A Python-based web application for analyzing Instagram engagement metrics and generating actionable insights through interactive visualizations. Processes CSV/API data to identify high-performing content types, optimal posting times, and audience trends while ensuring privacy with transient data processing.

## ✨ Key Features
- **Post-Type Analysis**: Compare Reels, Photos, and Stories performance (likes, shares, saves).
- **Time-Based Trends**: Heatmaps for hourly/weekly engagement peaks and monthly growth trends.
- **Topic Insights**: Auto-categorize posts by keywords (e.g., "Career Growth") and track their impact.
- **Viral Post Detection**: Flag posts with impressions >1.5× the average.
- **Strategy Recommendations**: Get optimal posting times and content themes.
- **Privacy-First**: No permanent data storage—processes CSV/API data temporarily.
